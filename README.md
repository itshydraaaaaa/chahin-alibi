# Chahin Alibi — Personal Portfolio

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

Official personal portfolio website of **Chahin Alibi** — Senior Graphic Designer, Founder of Asteria, Event & Podcast Host, and Engineering Student at ESPRIT based in Ariana, Tunisia.

---

## 🌟 Overview

This portfolio showcases brand identity systems, digital design, live event productions, and creative directions crafted by Chahin Alibi, including:
- **Asteria Branding & Productions:** Visual systems, apparel drops, and UI kits.
- **Hydra Series:** Conceptual artworks, visual series, and promotional animations.
- **Featured Client Projects & Case Studies:** Kingdom, Asteria Freelance, Club Esprit, and Bookshop.
- **Curriculum Vitae:** Full background, skill breakdown, and career milestones.

---

## 🛠️ Tech Stack

- **Frontend:** React 18 (Client-side interactive UI & smooth animations)
- **Styling:** Modern Tailwind CSS with custom typography & responsive design tokens
- **Typography:** Bricolage Grotesque, Hanken Grotesk, JetBrains Mono
- **Deployment:** Vercel

---

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18+) or any static HTTP server (Python 3, Nginx, or `serve`)

### Running Locally

#### Option 1: Using Python
```bash
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

#### Option 2: Using Node `serve`
```bash
npx serve .
```

## 🌐 Deployment to Vercel

The site is fully static and configured for instant zero-config deployment on [Vercel](https://vercel.com):

1. Import this repository into your Vercel Dashboard.
2. Set the root directory to `./`.
3. Deploy!

Alternatively, using the Vercel CLI:
```bash
vercel --prod
```
